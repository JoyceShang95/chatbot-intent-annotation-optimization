# Overseas Customer-Service Chatbot — Intent Annotation & Optimization Demo

This portfolio demo shows how international customer-service experience can transfer to AI chatbot operations: intent taxonomy design, annotation guidelines, hard-negative identification, error analysis, knowledge-base optimization, and cross-functional recommendations.

## Demo scenario
A global e-commerce customer-service chatbot receives English consumer questions. The goal is to improve intent recognition and route customers to the right knowledge-base flow.

## What is included
- `data/customer_queries.csv` — 50 labeled examples with model predictions and confidence scores
- `annotation/annotation_guideline.md` — annotation standard and boundary rules
- `analysis/analysis_summary.md` — error analysis and optimization actions
- `knowledge_base/faq.md` — sample knowledge-base content
- `app/chatbot_demo.html` — interactive offline portfolio page

## Portfolio talking point
The key point is not that a real model was trained. The point is that the candidate can define a business problem, turn conversations into structured labels, identify model/annotation failure modes, and convert those findings into data, guideline, and knowledge-base improvements.

## Suggested 3-minute walkthrough
1. Explain the business scenario and 10-intent taxonomy.
2. Show the `order_tracking` vs `delivery_delay` boundary case.
3. Show that the model is 80% accurate on this small demo set and point out low-confidence/confusion samples.
4. Explain how you would add hard negatives, refine guidelines, and close knowledge-base gaps.
5. Connect the method to real customer-service operations: multilingual users, complex cases, knowledge-base maintenance, and collaboration with product/AI teams.
